# SpendNest — Revenue Intelligence Inbox

SpendNest Revenue Intelligence Inbox is a web application that helps sales managers organize and analyze call records, meeting records, and conversation transcripts in one place.

The application processes incoming data, handles duplicate records and late-arriving updates, and keeps track of conversation routing and manual corrections. It provides a dashboard to monitor activity, an inbox to review individual records, and a manager brief highlighting important findings and actions.

### Key Features

- **Dashboard:** View call and meeting activity, transcript coverage, and routing status.
- **Conversation Inbox:** Search, filter, and inspect calls and meetings.
- **Data Processing:** Import initial and update batches with duplicate detection and revision handling.
- **Route Governance:** Track routing decisions and preserve manual route corrections.
- **Manager Brief:** Review key findings, risks, and recommended actions.
- **Export:** Download organized records and a manifest in a ZIP archive.

### Tech Stack

- React
- TypeScript
- Vite
- CSS

### Run Locally

```bash
npm install
npm run dev
```

Run the automated replay tests with:

```bash
npm run test:replay
```
